# Whatbytes E-Commerce Platform

A responsive e-commerce web application built with Next.js 14 (App Router), Tailwind CSS, and TypeScript, designed to match the Whatbytes assignment specification.

---

## 🔗 Links

- **Live Demo:** [whatbytes-ecommerce-assignment.vercel.app](https://whatbytes-ecru.vercel.app/)

## ⚡ Tech Stack

| Category | Technology |
| :--- | :--- |
| **Framework** | Next.js 14 (App Router) |
| **Language** | TypeScript |
| **Styling** | Tailwind CSS |
| **Icons** | Lucide React |
| **State Management** | React Context API + localStorage |
| **Deployment** | Vercel |
